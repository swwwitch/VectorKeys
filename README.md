# VectorKeys
macOS utility for organizing Illustrator scripts, reusable components, and hotkey actions.

## 1.21.0 (build 38)

Canonical source: [`880ffcb7e873940c7ffd48d27c0d94abb1e6f2f3`](https://github.com/swwwitch/macos-apps/commit/880ffcb7e873940c7ffd48d27c0d94abb1e6f2f3). The app sources and required shared components retain the original Bundle ID and settings. See [documentation and change history](VectorKeys/README.md).

Build: `./build.sh` (Apple Silicon, macOS 13+, Xcode command line tools and a suitable signing identity). Test: `cd VectorKeys && ./test.sh`. The default build does not deploy. Distribution signing, notarization and runtime verification are recorded separately.
